Explanation:

background-image: You can specify multiple images by separating the URLs with commas. In this case,left bottom corner flower image is the first background image, and right bottom multiple flowers image is the second background image & navy blue image is the third background image.

background-position: Defines the position of each background image. You can set different positions for each image (e.g., left top for the first image, right bottom for the second).

background-repeat: This controls whether the background images should repeat. In this example, the first image won’t repeat (no-repeat), while the second image will repeat (repeat).

background-size: This control the size of background images. It can be used to scale images in the background of an element to fit or cover a certain area, or to define custom dimensions for the background images. In this example for first & second image using auto means the background image will keep its original size (without any scaling) & for third image using cover means the background image will completely covers the element's background area. It ensures that the image fills the entire area.
